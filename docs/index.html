Approach
Measure once, math forever
1

Fenwick tree

Heights go into a Binary Indexed Tree. O(log n) for both queries and updates. Cumulative offsets are always instantly available.

2

Binary search

Given scrollTop, find visible items via O(log n) binary search. Both start and end. Pure arithmetic on Float64Array.

3

Minimal DOM

Only visible items plus overscan in the DOM. Positioned with translateY from pre-computed offsets. No measurement needed.

Code
Get started
react-example.tsx 
import { useRef, useMemo } from 'react'
import { FixedHeightProvider } from 'zero-scroll'
import { useVirtualScroll } from 'zero-scroll/react'

function Feed({ items }) {
  const scrollRef = useRef(null)
  const provider = useMemo(() => new FixedHeightProvider(64), [])

  const { items: visible, totalHeight } = useVirtualScroll({
    count: items.length,
    heightProvider: provider,
    scrollRef,
  })

  return (
    <div ref={scrollRef} style={{ height: 600, overflow: 'auto' }}>
      <div style={{ height: totalHeight, position: 'relative' }}>
        {visible.map(({ index, offset, height }) => (
          <div key={index} style={{
            position: 'absolute',
            transform: `translateY(${offset}px)`,
            height,
          }}>
            {items[index].text}
          </div>
        ))}
      </div>
    </div>
  )
}

const ps = new PrefixSum(100_000)
items.forEach((item, i) => ps.update(i, item.height))
